# Nguyen Nhat Nam - Mobile Engineer Portfolio Website

This portfolio website showcases Nguyen Nhat Nam's professional mobile engineering achievements, commercial projects, architecture patterns, and technical skills.

## Features
- **Modern Glassmorphic Dark UI**: Designed according to top-tier tech portfolios with neon accents, code snippets, and interactive elements.
- **Full Project Showcases with Mockups**:
  - **ClearHear App**: On-Device Live Captioning & Offline AI Summarization App (sherpa-onnx, flutter_llama / Qwen2.5 GGUF, GetX, SQLite).
  - **Generator Mobile Apps (Canvas Living)**: Multi-tenant White-Label Community Platform deployed across 20+ brands with App Store live link.
  - **Rentle Mobile (Vesta App)**: PropTech Tenant Lifecycle Platform with KYC, digital signature, and App Store live link.
- **Modal Image Zoom**: Click on any phone mockup to view the high-resolution screenshot in full size.
- **Fast & Zero Dependencies**: Built with pure semantic HTML5, CSS3, and vanilla JavaScript. No complex build step required.

## Live Preview
To preview locally, open `index.html` directly in any web browser, or run:
```bash
python3 -m http.server 4173
```
Then visit `http://localhost:4173` in your browser.

## Deployment Options
- **GitHub Pages**: Push this directory to your GitHub repo and enable Pages under Settings > Pages.
- **Vercel / Netlify**: Connect repository or run `npx vercel` / `npx netlify deploy` for instant deployment.
